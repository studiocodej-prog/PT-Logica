🚀 COMECE EM 3 PASSOS!

Passo 1: Execute o Programa de Exemplo (Pronto para Rodar!)
─────────────────────────────────────────────────────────

  Abra o terminal (cmd.exe ou PowerShell) em PT-Lógica/bin/

  Digite:
    .\programa_exemplo.bat

  Você verá:
    ✓ Detecção automática de hardware
    ✓ Simulação de compilação
    ✓ Execução completa com monitoramento


Passo 2: Abra o Editor (Interface Gráfica Completa)
─────────────────────────────────────────────────────

  No terminal principal, execute:
    python editor\editor_pt_logica.py

  Você terá acesso a:
    ✓ Editor com syntax highlighting
    ✓ Console de saída
    ✓ Biblioteca de funções
    ✓ Exemplos prontos para inserir


Passo 3: Compile Seu Primeiro Programa
────────────────────────────────────────

  Crie um arquivo chamado 'meu_programa.ptlogica' com:

    PT-inclusao>"PT-cpu"<
    PT-pt(hello)<
        PT-pt()<escrever{"Olá do PT-Lógica!"}>
    PT-pt()>finalizar
    PT-pt()<executar>

  Compile com:
    compilar.bat meu_programa.ptlogica

  Execute:
    .\meu_programa.exe

📚 90 BIBLIOTECAS EM 9 GRUPOS

Cada grupo tem 10 funções especializadas:

1️⃣  CPU (PT-CPU-01-a-10)
    Controle direto do processador, cache, núcleos

2️⃣  GPU (PT-GPU-11-a-20)
    Renderização 3D, shaders, ray tracing

3️⃣  MEMÓRIA (PT-MEMORIA-21-a-30)
    Alocação, heap, paginação virtual

4️⃣  STORAGE (PT-STORAGE-31-a-40)
    I/O de disco, RAID, criptografia

5️⃣  INTERFACE (PT-INTERFACE-41-a-50)
    GUI, widgets, eventos, temas

6️⃣  SISTEMA OPERACIONAL (PT-SO-51-a-60)
    Kernel, drivers, segurança

7️⃣  IA (PT-IA-61-a-70)
    Deep learning, NLP, computer vision

8️⃣  CLOUD (PT-CLOUD-71-a-80)
    Web servers, databases distribuídos

9️⃣  DADOS (PT-DADOS-81-a-90)
    ETL, data warehouse, big data

💡 EXEMPLOS RÁPIDOS

Exemplo 1: Ativar CPU
─────────────────────

PT-inclusao>"PT-cpu"<

PT-pt(processar)<
    PT-pt()<Abrir-codigo><conversar-processador-cpu>
        PT-pt(ativar-nucleos)<
            PT-pt()<nucleo-1{ativo}>
            PT-pt()<nucleo-2{ativo}>
            PT-pt()<nucleo-3{ativo}>
            PT-pt()<nucleo-4{ativo}>
        PT-pt()>finalizar
    PT-pt(Fechar-codigo)<terminar>
PT-pt()>finalizar

PT-pt()<executar>


Exemplo 2: Renderização GPU
───────────────────────────

PT-inclusao>"PT-gpu"<

PT-pt(render-3d)<
    PT-pt()<carregar-shader-vertex>
    PT-pt()<carregar-shader-fragment>
    PT-pt()<renderizar-triangulos{1000000}>
PT-pt()>finalizar

PT-pt()<executar>


Exemplo 3: Alocação de Memória
──────────────────────────────

PT-inclusao>"PT-memoria"<

PT-pt(alocar)<
    PT-pt()<malloc{2GB}>
    PT-pt()<heap-status>
PT-pt()>finalizar

PT-pt()<executar>

⚙️  COMPILAÇÃO

Método 1 - Simples (Recomendado para iniciantes)
──────────────────────────────────────

Isso cria: seu_programa.exe


Método 2 - Com Saída Customizada
────────────────────────────────

Isso cria: meu_app.exe

────────────────────────────

python compilador\compilador_exe.py seu_programa.ptlogica

Isso cria: seu_programa.exe

🔧 TROUBLESHOOTING

❌ "Python não encontrado"
   └─ Instale Python 3.8+ de python.org

❌ "Arquivo .ptlogica não existe"
   └─ Verifique se o arquivo está no mesmo diretório

❌ "Editor não abre"
   └─ Instale Tkinter: pip install tk

❌ "Compilador não encontra CSC"
   └─ Use o método Python ou Batch em vez de C#

🎓 ESTRUTURA DE UM PROGRAMA PT-LÓGICA

// Comentário de linha única

/* Comentário
   multi-linha */

// 1. Incluir bibliotecas
PT-inclusao>"PT-cpu"<
PT-inclusao>"PT-gpu"<

// 2. Definir função principal
PT-pt(programa-principal)<
    
    // 3. Abrir comunicação com hardware
    PT-pt()<Abrir-codigo><conversar-processador-cpu>
    
        // 4. Suas operações aqui
        PT-pt(fazer-algo)<
            PT-pt()<instrucao1>
            PT-pt()<instrucao2>
        PT-pt()>finalizar
        
    // 5. Fechar comunicação
    PT-pt(Fechar-codigo)<terminar-de-conversar>
    
PT-pt()>finalizar

// 6. Executar programa
PT-pt()<executar>
