🎯 O que é PT-Lógica?
PT-Lógica é uma linguagem de programação revolucionária que permite comunicação direta com o hardware (CPU, GPU, Memória, SSD) usando sintaxe em português.

Características Principais
✅ Sintaxe em Português - Escreva código que você entende
✅ 90+ Bibliotecas Especializadas - CPU, GPU, Memória, I/O, IA, Cloud, etc.
✅ Acesso Direto ao Hardware - CPU, GPU, Cache, Memória virtual
✅ Editor Gráfico Integrado - Ambiente completo de desenvolvimento
✅ Compilador para EXE - Gere executáveis Windows
✅ Ideal para IAs, SOs e Sistemas Complexos - Performance equivalente ao C++

🚀 Primeiros Passos
1️⃣ Executar o Programa de Exemplo
cd bin
programa_exemplo.bat
2️⃣ Abrir o Editor
python editor\editor_pt_logica.py
3️⃣ Compilar um Programa
python compilador\compilador_exe.py seu_programa.ptlogica -o seu_programa.exe
📝 Sintaxe Básica
// Incluir bibliotecas
PT-inclusao>"PT-cpu"<
PT-inclusao>"PT-gpu"<

// Programa principal
PT-pt(programa)<
    PT-pt()<Abrir-codigo><conversar-processador-cpu>
        PT-pt(ativar-nucleos)<
            PT-pt()<nucleo-1{ativo}>
            PT-pt()<nucleo-2{ativo}>
            PT-pt()<nucleos{4}>
        PT-pt()>finalizar
    PT-pt(Fechar-codigo)<terminar-de-conversar>
PT-pt()>finalizar

// Executar
PT-pt()<executar>
